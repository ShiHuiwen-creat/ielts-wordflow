# IELTS 候选学习资料

本目录汇总可供 IELTS 学习者参考的个人笔记与公开学习资料。资料按用途分类，便于检索和后续维护；它们不会被打包进 WordFlow 网页应用。

## 目录

- `personal-notes/`：从个人 Obsidian 笔记中筛选的复盘、词汇、听力、阅读、写作和口语总结。
- `assets/`：个人笔记引用的图片。
- `open-materials/vocabulary/`：词汇与词根资料。
- `open-materials/listening/`：听力资料。
- `open-materials/writing/`：写作资料。
- `open-materials/speaking/`：口语资料与题库。

## 来源与授权

仓库维护者于 2026-09-29 确认 `open-materials/` 中的文件可公开分发。各文件仍归其原作者或权利人所有，项目根目录的 MIT License 和词库的 CC BY 4.0 **不适用于**这些 PDF、DOCX 与图片。再利用资料前，请以文件内的署名、来源和上游许可为准。

个人笔记来自仓库维护者的学习记录，已在导入前检查明显的姓名、证件号码、考试安排、联系方式与详细履历。两份包含详细个人履历的笔记、一份准考证以及成绩与学历验证材料没有收入仓库。原始 Obsidian 文件没有被修改。

## 使用说明

- GitHub 可以直接预览 Markdown 和多数图片；PDF/DOCX 需要下载或由 GitHub 的预览器打开。
- `墨墨单词本-7045-250902.pdf` 约 76 MB，克隆仓库时会占用较多空间。
- 笔记中的第三方题目、示例和截图可能有独立的使用条件；公开可访问不等于放弃署名或其他许可要求。
- 如发现隐私、错误归属或许可问题，请通过仓库 Issue 提交移除请求；敏感信息请按照项目的安全报告流程私下反馈。
