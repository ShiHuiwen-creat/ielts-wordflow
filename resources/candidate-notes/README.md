# IELTS 候选学习资料

本目录汇总可供 IELTS 学习者参考的个人笔记与公开学习资料。资料按用途分类，便于检索和后续维护；它们不会被打包进 WordFlow 网页应用。

## 目录

- `personal-notes/`：从个人 Obsidian 笔记中筛选的复盘、词汇、听力、阅读、写作和口语总结。
- `assets/`：个人笔记引用的图片。
- `open-materials/vocabulary/`：词汇与词根资料。
- `open-materials/listening/`：听力资料。
- `open-materials/writing/`：写作资料。
- `open-materials/speaking/`：口语资料与题库。
