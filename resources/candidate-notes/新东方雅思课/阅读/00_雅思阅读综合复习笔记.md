## 一、考试介绍、时间分配与篇章统筹

### 1. 考试结构与时间节奏
- **题量与时长**：60 分钟完成 3 篇文章、共 40 题（6.5 分大致对应 27–29 题正确，7 分约 30 题）。
- **推荐时间分配**：第一篇约 **18 分钟**，第二篇约 **20 分钟**，给第三篇至少留 **18–20 分钟**；单题卡住超过约 1 分钟果断标记跳过，保住易得分题。

### 2. 题型组合与平行作答策略
拿到一篇文章先别埋头从第 1 题做起，花 30–60 秒扫一眼题型组合：
- **判断相对位置（拼接 vs 交叉）**：圈出两组题中的大写专名、数字、引号等显眼词，回原文扫一眼它们的前后分布。
  - **拼接**：一组结束后另一组才开始，按顺序做即可。
  - **交叉**：两组题答案穿插出现，可采用**平行作答**（按文章段落推进，每读一段同步核对相关题组；做完一道顺序题立刻补看下一题定位词），特别适合机考左右分屏。
- **跨题型顺序原则**：
  - 优先做**定位明确、段落集中**的题（如带明显专名的填空、判断、单选）。
  - **段落信息配对**若与其他题混合，通常放后做（借助已读段落和已做题目的记忆），或与人名/填空平行按段推进。
  - **利用未覆盖段落**：例如单选依次落在第 1、2、3、4、6 段，那么第 5 段大概率对应同篇的判断或填空。

## 二、填空题（无词库填空 & 选词填空）

### 1. 无词库填空（Summary / Note / Sentence / Table / Diagram / Short-answer）
- **通用六步法**：**审题（看字数限制）→ 定位 → 预测（词性/单复数/语义）→ 寻找 → 抄写原文词 → 检查**。
- **定位技巧**：
  - 优先圈 **大写专名、数字、符号**，其次选 2–3 个稳定名词短语（名词替换率相对较低，动词/形容词替换更灵活）。
  - 若小标题与大标题不同，可直接作定位锚点；若只是重复大标题，定位价值低。
  - 绝大多数填空按文章顺序出题（尤其是 Sentence Completion）。
- **铁律**：必须抄**原文原词**（不得自己改写同义词），严守 `ONE WORD ONLY`、`NO MORE THAN TWO WORDS` 等字数限制；机考可直接复制粘贴防拼错。
- **避坑**：
  - 看清后置修饰语（如 `made of...`、定语从句、介词短语），别把修饰成分误填成核心答案。
  - 两个候选词都通顺时，比较**语义具体度**（例如一词限制下，具体对象 `young` 优于泛指 `colony`）。

### 2. 选词填空（有词库 Summary）
- **七步闭环**：**审题（查是否有 NB / 词库可否复选）→ 画定位与逻辑词 → 预测词性 → 回文找句群 → 比对同义替换与上下文逻辑 → 填选项字母 → 回读检查**。
- **核心提醒**：
  - 词性只能缩小候选范围，最终必须靠**同义替换 + 上下文逻辑**拍板（如 `intellectual humility ↔ modesty`、`impartiality ↔ objectivity`、`symbiotic ↔ partnership`）。
  - 选项表是乱序的，且并列空格不一定按原文先后对应，要逐空核对各自语义。
  - 文中未设空的并列特征是极好的**排除锚点**，不要硬给每个特征都配空。

## 三、判断题（T/F/NG & Y/N/NG）

两种标签判定逻辑完全相同，核心是**比较完整语义与逻辑关系**，不靠常识脑补：
- **TRUE / YES**：整体语义一致（常为同义替换或双重否定等价，如“大多数群居”与“很少不群居”一致）。
- **FALSE / NO**：同一对象、同一范围/条件下**互相矛盾、不能共存**（不只是反义词，也包括数字/时间/顺序冲突，如“不足百年” vs “三百年前”，“自主选择 `choose`” vs “被分配 `assigned to`”）。
- **NOT GIVEN**：原文未提供决定结论的关键信息（与原文可并存，如提了猫没提狗、说了手工耗时没说价格、说了实验指令没说参与者是否知道实验目的）。

### 做题流程与五大高频考点
- **两题一组定位**：判断题基本顺序出题；两题一组找，若第 2 题在前、第 3 题在后且中间无对应信息，可高效确认第 2 题为 NG。
- **五大高频考点核对表**：

| 考点类型 | 核对要点 | 典型判定 |
| :--- | :--- | :--- |
| **1. 比较关系** | 核对比较双方 A/B 是否都出现、是否存在比较、比较维度是否一致 | 原文只比同卵/异卵双胞胎，未提 `non-twins` → **NG**；注意隐含比较对象（如实验室 vs 野外） |
| **2. 因果关系** | **先用结果定位**（结果不在 → NG）；结果在再看原文是否给原因 | 没说原因 → **NG**；原因不同 → **FALSE**；因果一致 → **TRUE**（分清 `result from` 表原因 vs `result in` 表结果） |
| **3. 绝对范围词** | 圈出 `only, all, every, the first, now` | 找到一个反例即可判 **FALSE**（如裸鼹鼠推翻“蚂蚁是唯一”）；与“所有先前研究”明确对比成立则 **TRUE** |
| **4. 时间与顺序** | 圈出 `already, before, after, first, will` | 建造/发生顺序相反 → **FALSE**；未完成 `unfinished` 与“已建成”矛盾 → **FALSE** |
| **5. 数字与比例** | 核对**对象、分母、时间与统计口径** | 题干说“90% 捕获鱼属某两种”，原文说“90% 北美商业捕获鱼产自某地”，口径不同 → **NG** |

## 四、选择题（单选题 & 多选题）

### 1. 单选题（顺序出题，多为一题一段）
- **三步法**：① 用题干段号/关键词先标出各题所在段（机考在草稿纸记 `题号—段号`）；② 看清问题焦点（观点 / 例证作用 / 细节），**本身正确但没回答题干的选项不选**；③ 回文逐项核对，借判断题思维排除 False / NG 干扰项。
- **三大考法对策**：
  1. **主旨/观点类**（*What point did the writer make...?*）：通读该段，抓长句主干与 `although / but / yet` 后的真正重点，将原文具体陈述压缩为抽象概括。
  2. **例证作用类**（*Why does the writer mention...?*）：**优先读例子前的论点/总结句**；若论点句已足够回答题目，可不必细读例子本身。
  3. **细节类**：精准核对对象与关系，警惕常见偷换（如把“随情境变化”偷换为“人与人不同”、把“适应环境”偷偷加上没证据的 `quickly`、把无因果关系的信息强行连成因果）。

### 2. 多选题（五选二等，乱序，两项可能跨段）
- **步骤**：先用题干定位段落（若专名全文高频出现，则按段平行读）；**每读 1–2 句就回到选项核对**，同义替换确认、原文证据排除。
- **避坑**：
  - 区分“主题相关”与“关系成立”（原文同时出现识字率与经济增长，但因果方向反了就不能选）。
  - 选项必须**整体成立**，警惕只凭一两个原词（如 `solar / wind`）误选。
  - 找到第一个答案后继续往后读，两个答案可能分布在不同段落。

## 五、配对题（人名配对、段落信息、短句配对）

### 1. 人名/特征配对（乱序，可能复选）
- **核心规律**：人名在原文**首次出现的顺序**通常与选项顺序一致，但题目观点与文章是**乱序**的。
- **实操四步**：
  1. 读说明确认能否复选（留意 `You may use any letter more than once`，机考不一定标醒目的 NB），数题数与选项数预估分布。
  2. 圈出人名（注意原文可能只出现姓、名或首字母）并快速扫全文，**统计每人出现的段落与次数**。
  3. **先读出现次数少、信息集中的人物**（易快速锁定并消掉选项），读时略过学校/头衔等纯背景，直抓观点与指代（如 `that earlier view` 需回看前文）。
  4. 按观点同义改写与正负态度匹配，不要因“刚读到某人”就强行配题。

### 2. 段落信息匹配（`Which paragraph contains...`，乱序，定位最难）
- **审题三步**：① 看题型组合（优先后做，借其他题熟悉段落）；② 查复选说明、数段落与题数估算干扰段；③ **一次性读完并翻译全部题干**，略过空泛框架词（`factors, reference to, mention, description of, belief`），圈出真正核心对象、动作、立场及强特征词（组织专名、数字 `figures`、`exact point`、`particular + 名词` 常在原文具体化为某物种/植物）。
- **做题闭环**：按段阅读，**每读 1–2 句即对照所有未完成题干核对**；切忌只看首尾句（首尾句命中率不高，细节常在段中）；确保题干所有限定条件落在**同一批对象**上，禁止跨句拼接。

### 3. 短句配对（Sentence Endings，顺序出题）
- **策略**：虽是顺序题，但替换密集，建议**两至三题一组**圈定位词，做到“两点确定一条直线”（专名 + 动作/关系），找到哪题先做哪题；利用剩余选项和文章主题做有依据的排除，不要逐题死磕。

## 六、段落标题题（List of Headings）

考查**段落组织与中心思想**（非局部细节），选项多于段落且**不可复选**（若有示例项，先划掉）。

### 四步实战法
1. **读段优先级**：
   - 短段（4–5 句）直接通读。
   - 长段**先读首二句**找中心句；若前两句只是背景/例子，再看**末句**和段内 **转折词（`but / however / yet / unfortunately`）** 后的重点。
   - 若一个 Section 含多个小段，需拆解各小段主旨，选能**覆盖整节**的标题。
2. **选项“核心名词 + 限定条件”联合核对**：
   - 例如“金字塔内部的区域和文物”必须同时有“内部区域”和“文物”；比较相似选项先抓差异词（如 `within` vs `external`）。
3. **抓概括而非局部词**：看到一个细节词不等于段落主旨，始终问“这一段整体在讲什么”。
4. **不确定先记备选**：宁可先留空写 2 个候选，等其他段用掉干扰项后再回填，避免“错一个连带错一串”。

## 七、长难句抓主干与高频同义替换

### 1. 长难句快速拆解
- **先找主谓，后看修饰**：从句首名词/动名词找主语（跳过介词短语、插入语、破折号、`over the course of...` 等时间背景短语），锁定核心谓语动词。
- **善用标点**：冒号前常是抽象总结，**冒号后或引号内**常是具体易懂的解释；前半句卡壳先读冒号后。
- **紧盯逻辑词**：`although / while` 表让步，重点在主句；`but / however / yet` 后常是作者真正观点。

### 2. 学术阅读高频同义替换速查
- **研究与实验类**：`experiment / study / research / investigation`；参与者 `participants / subjects / volunteers`；`be aware / learn / perceive`；`sample`（样本）vs `population`（总体）。
- **特质与先天/后天**：`personality / trait / characteristic / quality / feature / nature`（`nature` 也可指“性质”）；先天 `heredity / DNA / genetic / innate`。
- **高频动作与概念替换**：
  - 复制/模仿：`reproduce / copy / duplicate / replicate / imitate / mimic`
  - 公开/标准：`transparency ↔ open`；`standards ↔ criteria`
  - 批评/反对：`criticise ↔ blast / condemn`；`oppose ↔ against`；`monopolies ↔ control over a trade`
  - 数量与时间：`triple ↔ three times`；`outlive ↔ live longer than`；`not simply / not just`（不仅仅）

## 八、日常练习与错题复盘清单

1. **三格核对判断题**：复盘时把错题拆成「题干主张（主语+动作+限定）｜原文证据｜关系（一致/矛盾/缺信息）」，彻底分清 False 与 Not Given。
2. **建立个人同义替换本**：只记录自己**做题时没认出来**的替换（如概括↔具体、词性转换、跨句指代），不要抄整本词典。
3. **限时套题训练节奏**：平时按 18 / 20 / 20 分钟卡表练整套三篇，刻意训练“先扫题型定顺序 → 交叉题尝试平行作答 → 难题标记跳过”的考场手感。
4. **错题归因顺序**：先查是否**没读懂题干/选项限定** → 再查**定位段是否找错** → 最后查**长句修饰关系、转折方向或同义替换**是否漏看。
