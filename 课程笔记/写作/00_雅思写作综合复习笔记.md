## 一、考试介绍、权重与评分标准

### 1. 基本规则与机考要点
- **总时长 60 分钟**，先写 **Task 2（大作文，占 2/3 权重）**，再写 **Task 1（小作文，占 1/3 权重）**。
- **字数目标参考**：
  - **Task 2**：最低 250 词（6.5 分建议 280 词左右，7 分 300+ 词；建议用时 40 分钟）。
  - **Task 1**：最低 150 词（6.5 分建议 150–180 词，7 分约 200 词；建议用时 20 分钟）。
- **机考提醒**：答题框实时显示 word count，但**不会明显提示拼写错误**，每篇务必留 1–2 分钟查拼写、单复数和主谓一致；考前用普通键盘练打字速度。

### 2. 四项评分标准与提分抓手（降分制：`7/7/7/6 → 6.5`）
1. **TR / TA（任务回应 / 完成）**：大作文看**立场清晰、全面回应对象与限制词、论证扣题且拓展充分**；小作文看**客观汇报可见数据、有清晰概述、不主观推测图外原因或未来**。
2. **CC（连贯与衔接）**：靠三类手段——① 显性连接词（与逻辑匹配）；② 新旧信息回指（`this/it/one/such + n./by doing so`，忌用 `you` 泛指读者）；③ 非谓语/定语从句压缩结果（`..., potentially leading to...` / `..., which results in...`）。
3. **LR（词汇资源）**：**准确、语域正式、搭配自然**优先于生僻词。
   - 避免口语/俚语/缩写：`kid → child`、`boss → manager/supervisor`、`let sb do → allow/enable sb to do`、`a lot of → numerous / a large number/amount of`、`can't → cannot`、少用句首 `so`。
   - 避免直接提问、感叹句、祈使句，以陈述句为主。
4. **GRA（语法范围与准确度）**：**错误少**优先于冒险堆复杂句。熟练掌握一般现在/过去/将来/现在完成时，以及比较结构、情态动词、被动语态、三大从句与非谓语。

## 二、Task 2 大作文：审题、立场与结构框架

### 1. 审题三步法（限 5 分钟内含列提纲）
1. **看问法判题型**：议论文（同意与否 / 双边讨论 / 利弊比较）、说明文（原因/影响/措施）、混合题（一问说明 + 一问议论）。
2. **圈讨论对象**：多对象必须全覆盖（如“音乐团结不同**文化**与**年龄**人群”，两维都要写；手机禁令题要覆盖图书馆、商店、公共交通）。
3. **圈限制词**：形容词、副词、介词短语、范围词（如 *for communication*、*reading and writing skills*、*serious crimes*、*to a country*）都限定了论证边界，漏掉即偏题。

### 2. 全题型结构速查表

| 题型 | 核心策略与立场 | 推荐段落结构 | 引言与结尾核心句型 |
| :--- | :--- | :--- | :--- |
| **普通同意与否**（Agree / Disagree） | 先列双方各 2 点，选易论证一方；多数题推荐**偏向型「1+2」**（双方不冲突时可用分情况） | 5 段：引言 → BP1（对方 1 点 `Admittedly...`）→ BP2（转折回我方第 1 点 `However, while..., I believe..., as...`）→ BP3（我方第 2 点 `Moreover...`）→ 结尾 | 引言：改写题干 + `Although this view may have some validity, I am convinced that...` / `I largely agree with this view and believe that...`<br>结尾：`In conclusion, although [对方], I believe [我方立场与理由].` |
| **极端词题**（`only / best / all`） | 改写必须保留极端词；通常选**偏反对** | BP1 将 `only/best` 弱化为 `important/good` 承认部分合理性；BP2/3 直接反驳极端性或提出更优替代方案（如用拥堵费反驳“免费公交是最佳方案”） | 同偏向型「1+2」 |
| **对比题**（`better than / rather than`） | 保留 A/B 优劣方向，选 A>B 或 B>A（忌写“一样好”） | BP1 承认 B 的优点（不写“更好”）；BP2/3 写 A 的优点并用 `In contrast` **明确对照 B 的不足**，紧扣同一比较维度 | 同偏向型「1+2」 |
| **因果题**（`because / so`） | 保留 A→B 关系；通用稳妥路线为**承认原因 A、反驳结果 B** | BP1 承认原因成立（如网络资料丰富 / 政府资源有限）；BP2/3 反驳结论（如学校仍不可替代 / 援外也符合本国利益） | 同偏向型「1+2」 |
| **双边讨论**（Discuss both views） | 实质讨论双方 + 给出倾向 | 5 段「1+2」：一段写对方，两段写己方（若含极端词如 `the main` 需适度限定） | 引言：`Some people claim that A, while others argue that B. Personally, I tend to agree with the former/latter.` |
| **利弊比较**（Outweigh / Positive or negative） | 讨论客观现象，权衡利弊并明确哪侧更重 | 5 段「1+2」：先一段写较弱侧，再两段写更重侧 | 引言（忌用 *Some people claim*）：改写现象 + `While there are certain benefits, I believe the drawbacks are more significant.` |
| **说明文**（Causes / Solutions / Effects） | 客观回应问题，**不表个人立场** | 4 段：引言 → BP1（答第 1 问，2 个论点）→ BP2（答第 2 问，2 个论点）→ 结尾概括 | 引言：改写客观现象 + `This essay aims to explore the potential reasons behind this phenomenon and propose some feasible solutions.`（问惩罚则改为 `measures for punishing them`） |
| **混合题**（说明 + 议论） | 两类结构组合，且说明段与利弊段**论点不重复** | 5 段：引言（现象+目标+立场）→ BP1（答说明问，2 点）→ BP2（承认另一侧）→ BP3（我方立场）→ 结尾概括+重申立场 | 引言三合一：改写现象 + 探索目标 + 个人立场 |

## 三、Task 2 大作文：论点展开、例证与核心表达

### 1. 主体段黄金公式：论点（段首）→ 解释 → 具体细节/例证 → 回扣
- 论点不能停留在抽象判断，每段约 70–80 词（5–6 句）；逻辑推导控制在 **A → B → C**，切忌无限延伸跑题。
- **三大展开路径**：
  1. **现状/问题 → 推导 → 假设 → 回扣**：`Currently, it is widely observed that [现象], which suggests that [影响]. Therefore, [结果]. If [假设]. Thus, [回扣].`
  2. **原因 → 影响 → 举例 → 回扣**：`This is primarily because [原因], meaning that [影响]. A case in point is that [例子]. Hence, [回扣].`
  3. **解释 + 对比 → 回扣**：想不出例子或假设时，用 `By contrast, ...` 对比反面方案的弊端再回扣。
- **字数不够时**：优先给现有论点补另一个解释角度、加具体例子或对比，**一段最多 2 个论点**（1 个核心点展开透更佳）。

### 2. 例子层级与避坑
1. **针对性例子（说服力最强）**：具名机构、政策或人物（如英国 NHS、伦敦拥堵收费、BBC *Blue Planet*、南丁格尔、Elon Musk）。
2. **罗列范例（通用好用）**：用 5W1H 把抽象概念落到具体行业/群体/场景（2–3 个相关对象，如建筑工地与护理岗位、医生/教授/工程师）。
3. **个人个例（说服力最弱）**：“我曾经……”仅作兜底。
- **避坑**：不编造虚假数据/研究百分比；避免考官难懂的冷门民俗；慎用敏感政治/宗教例子。

### 3. 核心衔接与条件句
- **原因**：`because / as / since + 句子`；`because of / owing to / due to + 名词短语`；`The primary reason is that...`。
- **结果与导致**：`hence / thus / therefore / as a result / as a consequence`；`lead to / contribute to / result in + 名词短语`（接完整句必须改用 `which means that... / meaning that...`）。
- **举例与对比**：`For example / For instance`、`such as + 短语`、`A case in point / A typical example is that...`、`It is especially the case for sb who...`；`In contrast / By contrast / In comparison`、`while / whereas`。
- **条件句选择（重点掌握第一、第二条件句）**：
  - **第一条件句（可能发生）**：`If + 一般现在时, ... will / can / may / might + 动词原形`。
  - **第二条件句（反事实/极端假设，不表过去）**：`If + 一般过去时, ... would / could / might + 动词原形`（例：*If all residential houses were built in traditional styles, there would be fire risks...*）。

## 四、Task 1 小作文：静态图与动态图实战

### 1. 通用铁律与审题四步
- **四段式顺序**：**开头改写 → 概述（`Overall,` 不写具体数字！）→ 主体细节 2–3 段**。先写概述再写细节，防时间不够漏写概述。
- **图表准确命名**：`line graph`、`bar chart`、`pie chart`、`table`、`map / plan`、`flow chart / process diagram`。
- **审题四步**：
  1. **判静态/动态**：看数据是否**随时间变化**（线图必动态；若年份只是固定属性如地铁开业年、或单个时点，则属静态）。
  2. **判时态**：介绍图表用一般现在时（`shows / illustrates`）；主体数据按图中年份选时态（无时间用现在时，过去年份用过去时，未来计划用将来时；注意图例中藏着的时间词如 *in the last four weeks*）。
  3. **判单位与数据对象**：保留 `%` 及图例单位（如 *billion kilowatt hours*）；明确分子和分母，**不要把国家本身写成升降主体**（写 `the figure for Australia declined`，不写 `Australia declined`）。
  4. **决定分段**：**相似合并**（表现接近或高低分层的归一组）或**按图例分组**，目标让段内便于比较。

### 2. 开头改写与概述写法
- **开头改写**：`The bar chart below shows...` → `The given/provided bar chart illustrates / displays / gives information about...`；配合词性与句式转换（如 `production and consumption of electricity` → `how much electricity was produced and consumed`；`from... to...` → `between... and...`）。
- **静态图概述**：先抓**图例各系列的共同规律**（哪些类别整体突出/偏低），再比较**总量**（多张饼图则比各图主导类别）。
- **动态图概述**：**总体趋势（升/降/稳/波动）+ 一项突出特征**（变化幅度最大、始终最高/最低、明显转折）。

### 3. 静态图核心数据与比较表达
- **段首引导**：`Focusing initially on...,` / `Turning to...,` / `As for...,` / `In terms of...,`（后接逗号与主句）。汇报顺序：**先最大/最小值 → 再挑代表性中间值**（第二大、相近、倍数、区间）。
- **百分比三种主语交替用**（例：晚餐占钠摄入 43%）：
  1. 比例作主语：`The percentage/proportion of sodium intake from dinner is 43%.`
  2. 对象作主语：`Dinner accounts for / takes up / contributes 43% of sodium intake.`
  3. 数值作主语：`43% of sodium intake comes from / is consumed at dinner.`
- **极值、排名、区间与倍数**：
  - 极值：`the largest/smallest percentage, at 42%`；`Snacks contribute the most added sugar (42%).`
  - 排名与跟随：`ranks second / comes second`（不加 `the`）；`..., followed by dinner.`
  - 区间打包：`The percentages ... range from 16% to 23%.`；一一对应：`43% and 37%, respectively`。
  - 估值：`about / around / roughly / approximately / nearly`。
  - 倍数与分数：`A is twice / three times as large as the figure for B`（忌用易歧义的 *twice larger than*）；`be half of`（不加 `a`）、`one third of`、`two thirds of`。

### 4. 动态图核心趋势与衔接表达
- **主体段规则**：**把一个系列的趋势与数据写完整后再换下一个**，忌来回跳跃；交叉用 `overtook / surpassed / reached the same level as`。
- **四种趋势句型交替用**：
  1. 动词 + 副词：`The figure increased sharply from 100 to 600 between 1980 and 1990.`
  2. 经历名词：`The number of students showed/experienced a sharp increase from 100 to 600...`
  3. 存在句：`There was a sharp rise in the number of students...`
  4. 时间作主语：`The decade witnessed a sharp climb in the number of students...`
- **强趋势词**（本身已含大幅含义，不配 `slightly`）：上升 `soar / jump / surge`；下降 `plummet / plunge / slump`。
- **不变与波动**：
  - 不变：`remained unchanged/stable at 200` / `stabilized at 200`（`remain` 后接形容词，数值用 `at`）。
  - 波动：`fluctuated between 200 and 300 from 1980 to 1990` / `showed fluctuations between 200 and 300`。
- **介词铁律**：起终点 `from... to...`；变化量 `by + 数值`（名词用 `an increase of 200`）；不变用 `at`；波动上下限用 `between... and...`。
- **衔接先后趋势**：交替使用 `then / after that`、`before / after (+ 从句或动名词)`、`followed by + 名词短语`（如 *followed by a sharp decline to...*）。

## 五、Task 1 小作文：地图题与流程图实战

### 1. 地图题（Map / Plan）
- **结构与时态**：通常每张图一个主体段；历史图用过去时，today 用现在时，计划图用将来时。
- **概述（Overall）**：总结两件事——**哪些核心功能保留或新增**（不局限于名称变化，如音乐台→音乐剧场仍保留音乐功能），以及**整体变得更现代/休闲/多功能/交通更便利（`more accessible`）**。
- **初始布局写法**：按固定顺序（北到南、西到东或从中心/入口顺时针），优先写大设施，**优先用绝对方位（东南西北）**：
  - 方位介词：内部 `in the east of`；外部接壤 `on the east of`；外部不接壤 `to the east of`；对面 `A is opposite B` / `on the opposite side of B`（忌用 *above/below* 表南北）。
  - 组合句减重复：`A fountain was located in the centre of the park, with a stage to its west, a pond to its northeast, and a glasshouse to its southeast.`
- **地图变化四类（多用被动语态）**：
  1. 新增/拆除：`be built / constructed / added`；`be removed / demolished / knocked down`（`disappear` 不及物，无被动）。
  2. 面积变大/小：`be enlarged / extended / reduced`；`become larger/smaller`（无被动）。
  3. 替换用途：`be replaced by`；`be changed / turned / converted into`。
  4. 迁移/不变：`be relocated to...`；`remain unchanged`。

### 2. 流程图（Flow Chart / Process Diagram）
- **时态与语态**：全文用**一般现在时**，客观工业流程多用**被动语态**。
- **概述（Overall）**：写清**总步骤数 + 起点 + 终点**。
  > `Overall, the production of instant noodles involves eight steps, beginning with storing flour in silos and ending with labelling and sealing the cups.`
- **主体段逐步写法**：每步检查**原料、动作、设备、产物、目的**（图未标设备名可省略，不编造）。
- **步骤衔接多样化**：用阶段词（`In the initial phase...` / `Once this step has been completed...` / `In the subsequent stage...`）、`before / after` 从句、设备非限定性定语从句（`..., into a mixer, where it is mixed with...`），以及以上一步产物作下一步主语。

## 六、高频语法与词汇纠错清单

| 常见错误写法 | 正确写法 | 原因 |
| :--- | :--- | :--- |
| `old people` | `elderly people / seniors` | 正式书面语更礼貌自然 |
| `study/learn knowledge` | `acquire knowledge` | 固定动宾搭配 |
| `in my point` | `in my opinion / from my perspective` | 固定介词搭配 |
| `It was raining, therefore we stayed.` | `...raining, and therefore...` / `...raining. Therefore, ...` | `therefore` 是副词，不可像 `so` 直接连两句 |
| `because of it was raining` | `because it was raining` / `because of the heavy rain` | `because of` 接名词短语，`because` 接句子 |
| `lead to + 完整句子` | `lead to + 名词短语` / `..., which means that + 句子` | `lead to / contribute to / result in` 只能接名词短语 |
| `advertisement facilitates...`（泛指） | `advertising facilitates...` / `advertisements facilitate...` | `advertisement` 可数，泛指用不可数 `advertising` 或复数 |
| `the largest added sugar` | `the largest percentage of added sugar` / `the most added sugar` | `largest/highest` 修饰数值，不可直接修饰不可数名词量 |
| `The percentage ... is larger than breakfast.` | `...is larger than that at breakfast / the figure for breakfast.` | 比较对象必须同类（数值 vs 数值） |
| `ranks the second` | `ranks second / comes second` | 序数副词修饰动词不加 `the` |
| `remain unchangedly / stably` | `remain unchanged / remain stable at...` | `remain` 为系动词接形容词，不变数值用 `at` |
| `fluctuate from 200 to 300` | `fluctuate between 200 and 300` | 波动上下限用 `between... and...` |
| `A is opposite to B` | `A is opposite B` / `on the opposite side of B` | `opposite` 可直接作介词 |

## 七、复习计划与考场时间分配

### 1. 考场 60 分钟精确卡表
- **Task 2（40 分钟，先写）**：审题与列提纲 ≤ 5 分钟 → 引言 1–2 分钟 → 主体段约 30 分钟 → 结尾 1–2 分钟 → 检查拼写/单复数/主谓一致 1–2 分钟。
- **Task 1（20 分钟，后写）**：审题与分段 ≤ 3 分钟 → 开头 1–2 分钟 → 概述 2–3 分钟 → 主体段约 11 分钟 → 检查 1–2 分钟。

### 2. 备考优先级与练习节奏
- **Task 2 优先级**：高频话题优先准备**教育、社会、政府**类；题型优先吃透**同意与否（含极端/对比/因果）**，再练双边、利弊、说明、混合。
- **Task 1 优先级**：**动态图 → 静态图 → 地图 → 流程图**。短期集中写几篇动态图找手感，之后每周保持 1 篇；考前至少做 1–2 次全真 60 分钟限时模考。
