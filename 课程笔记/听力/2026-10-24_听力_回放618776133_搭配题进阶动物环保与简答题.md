# 搭配题进阶、动物环保场景与简答题

> 本讲开头承接搭配题练习，随后讲解搭配题分类、第四部分动物/环保题材与简答题。以下按课堂顺序整理，时间戳对应回放。例题答案只记录课堂明确给出的内容。

## 一、搭配题：状态题技巧及 Cambridge 17 例题

### 1. Sporting Equipment（Cambridge 17 Test 4 Part 3, p.79）

本讲开头接着上一讲酒店练习后的 **Sporting Equipment** 状态类搭配题。老师提醒需要理解原文解释，不要只根据一个相似单词猜选项。[00:00:00–00:13:00]

课堂分析的选项及答案：[00:02:18–00:12:50]

- **25 – B**：1920 年代工厂开始批量生产橡胶卷材（**rolls of rubber in bulk**），原本用于 **horse harnesses**（马具）；后来有人想到可用作木球棒的包覆材料。重点是理解“材料因另一用途而被批量生产”。[00:02:18–00:04:10]
- **26 – F**：板球头盔在 1978 年开始出现；第一位佩戴它的澳大利亚击球手被观众 **booed and jeered**（喝倒彩、嘲笑），因为头盔看起来很丑。老师将嘘声/喝倒彩解释为不受欢迎。不能误选 H：原文说观众不喜欢，不等于佩戴者本人不喜欢。[00:04:12–00:06:47]
- **27 – A**：认真训练的骑行者运动后头发湿透（**ended up with wet hair from all the hard exercise**）；老师解释新式头盔的大型 **air vents**（通风孔）帮助头部/皮肤透气，避免过度出汗。[00:06:49–00:08:46]
- **28 – D**：旧式高尔夫球杆容易坏，球手只好再拿一支；**get another one** 对应 **replace**（更换）。[00:08:47–00:09:21]
- **29 – C**：曲棍球杆题中，**does say here though** 用强调 **does** 加转折 **though** 提示后面重要信息：早期打球者要自己制作球杆。答案为 C。[00:09:58–00:11:10]
- **30 – G**：旧式足球雨天会进水，球变重；头球时可能伤害球员的颈部。**damage** 对应 **injury/injuries**；答案为 G。[00:11:11–00:12:50]

### 2. 状态题中的提示词

老师总结，状态题往往需要依靠语料和同义替换，但部分题目会用转折、总结或强调表达提示答案。课堂列出的表达如下：[00:12:52–00:15:28]

- 转折：**but**, **however**, **though / although**, **whereas**。老师特别提醒 **whereas** 的读音。
- 总结/结果：**so**。
- 强调/限制：**do / does**, **only**。

以第 29 题为例，强调词与 **though** 一起引出答案；第 30 题用 **but** 引出与此前描述相反的重要信息。[00:10:19–00:12:50]

老师给出一组常见状态题替换关系，并提醒原词和替换词的位置并非固定，可能双向转换：[00:32:41–00:39:35]

| 原词/意思 | 常见替换 |
|---|---|
| **must** | **have to**（两者可互换） |
| **limited** | **restricted**, **some**（课件该处需结合完整语境理解） |
| **conclusion** | **last part** |
| **useful** | **valuable**, **precious** |
| **boring** | **dull**, **uninteresting** |
| **difficult** | **hard**, **ambitious**（老师提示 *ambitious* 可委婉表示难度高） |
| **dangerous** | **risky** |
| **noisy** | **not quiet**, **screaming**（解释性表达） |
| **free** | **don’t have to pay** |
| **payment** | **pay**, **cost**, **price** |
| **economic** | **financial**；另提到 **profit**, **money** 作为关联表达 |
| **employment** | **recruitment**, **requirement**, **workload**（课上对这组词的具体对应关系有口误，见待核实） |
| **all / every** | **one**, **single**, **each** 等数量表达（依句义判断） |
| **ask** | **require**, **request** |
| **change(s)** | **variation** |
| **show** | **demonstration** |
| **purpose** | **intention**；**be supposed to**（本来计划/按原计划应当） |
| **other** | **alternative**（注意重音） |

老师强调，这些规律性替换只是辅助，难题仍要依靠听懂原句；补足搭配题相关语料库是长期准备的一部分。[00:30:32–00:34:23]

## 二、搭配题的时间题与态度题

### 1. 时间题：Cambridge 海洋浮标研究

老师按“宏观数量关系，再看选项含义”的顺序带题：该组题选项少于题目，因此选项在全都用到的前提下会重复使用；A/B/C 分别表示现在、近期未来、较远的未来。[00:39:44–00:42:52]

例题讨论的是浮标数据在海洋系统研究中的应用，课堂给出的答案：[00:43:00–00:48:50]

| 题目主题 | 答案 | 听力依据与课堂解释 |
|---|---|---|
| El Niño 成因 | **A / at present** | **is being confirmed** 是现在进行时被动，描述正在进行的确认工作。老师提醒不能只因看到 **be doing** 就判断未来；表示未来有语境限制。 [00:45:49–00:48:19] |
| 气候变化研究结果 | **C / long-term future** | **the results are still a long way off**。 [00:48:28–00:48:33] |
| 海洋天气预报/海上救援 | **A / at present** | **That’s happening right now**。 [00:43:43–00:43:57] |
| 可持续渔业做法 | **B / near future** | **quite soon**。 [00:44:03–00:44:20] |
| 农业应用 | **C / long-term future** | **still a long way in the future**。 [00:44:24–00:44:54] |

课堂归纳：时间大类是现在、过去、未来；现在常听现在进行时等表达，过去/未来可有多种时态，也要熟悉时间状语。老师举例提示 **past / previously / last / before**，以及 **in the future / soon**；还特别提示 **old** 可暗示过去、**new** 可暗示未来。[00:48:48–00:49:56]

### 2. 态度题：肯定、否定、犹豫

例题为小组确定报告主题的对话。题目包含地理位置、经济、教育系统概况、英语语言角色等议题；选项少于题目，选项全用且可重复。课堂答案：[00:51:17–00:54:37]

- 历史背景：**C / no**，对话明确说 **Oh no, definitely not**。
- 地理位置：**A / definitely**；对方接受记录建议。
- 经济：**B / maybe**；讨论后说 **Let’s think about that one later**，态度未定。
- 教育系统概况：**A / definitely**；回应 **Of course**。
- 英语语言角色：**C / no**；对方指出这属于另一场语言政策研讨会。

老师总结三种态度信号：[00:54:38–00:56:37]

- **肯定**：**yes, sure, certainly, of course, absolutely, no problem, positive**；也包括 **Leave it to me**、**I will do…** 等主动承担表达。
- **否定**：**no, definitely not, I don’t think so, will avoid…**, **not bother with…**。老师提示 **will avoid** 在连读中可能弱化。
- **犹豫/未定**：**well… actually… yes… but…**, **think about it later**, **try to do…**。

## 三、第四部分场景：动物、环保与睡蜥蜴题

### 1. 动物场景的词汇分类

老师指出动物和环保题材常见于 Listening Part 4，题材跨度大、规律性较弱；动物题常考三类信息：动物名称及拼写、动物特征/栖息环境、人类开展的研究。[01:10:39–01:12:27]

课堂词汇按听辨和拼写整理（仅保留课堂清楚讲到的词）：

- **动物名称**：[01:13:04–01:22:59] **koala**, **elephant**, **dolphin**, **ostrich**, **rhinoceros**, **shark**, **crocodile**, **falcon**, **lion**, **owl**, **shrimp**, **snake**, **snail**, **kiwi**, **kangaroo**, **penguin**, **seal**, **frog**, **tuna**, **hedgehog**, **wasp**, **camel**, **dinosaur**, **rat**, **spider**, **insect**, **worm**, **butterfly**, **rabbit**。老师提醒 **insect** 是昆虫的总称，**bug** 更常泛指小虫/令人讨厌的虫类；**butterfly** 的复数为 **butterflies**。
- **动物特征与环境**：[01:23:02–01:26:19] **coast**（海岸）、**species**（物种）、**breed**（繁育）、**kelp**（海藻）、**mane**（鬃毛）、**plant**, **nuts**, **leather**, **tide**, **parasite**（寄生虫；不要与 **paradise** 混淆）、**odour**（动物气味）、**nest**, **pest**, **predator**, **mate**（交配/伴侣，按上下文）。
- **人类调查研究**：[01:27:28–01:30:05] **rescue network**, **gene**, **genetic**, **humidity**, **spices**, **flourish**, **decline**, **navigation**, **phenomenon**（如 **social phenomenon**）。

### 2. Sleepy Lizard 填空题：审题与定位

老师以 **The Sleepy Lizard** 讲座作为 Part 4 填空例题。先确认答案字数要求（课堂提到不超过两词），再看标题、分段小标题和空格语法，判断答案词性；必要时画关键词，并留意定语、状语、被动语态、并列/转折等可能造成语序变化的结构。[01:30:33–01:43:40]

录音核心事实与课堂确认答案：[01:43:51–01:59:12]

| 题号 | 答案 | 课堂讲解与证据 |
|---|---|---|
| 31 | **tongue** | 睡蜥蜴身体为棕色，显著特征是深蓝色舌头；**which is dark blue** 是修饰 tongue 的定语从句。 [01:48:32–01:49:57] |
| 32 | **plants** | 虽吃昆虫和小动物，但主要吃植物；**mostly** 对应题目中的 mainly，答案复数需保留 s。 [01:50:01–00:50:56] |
| 33 | **snakes** | 过去主要捕食者包括大型鸟类；如今更可能被蛇捕食。注意转折及复数。 [01:50:57–01:51:14] |
| 34 | **sky** | 研究发现，即使被带离原栖息地，只要能看见天空，通常就能找到回家的路；**find their way back home** 对应题干的导航概念。地面 landmarks 是干扰项，因为录音说不需要其他地标。 [01:51:15–01:53:12] |
| 35 | **partner** | 观察发现睡蜥蜴相对一夫一妻，会年复一年回到同一伴侣身边；**year after year** 对应题目中的多年信息。 [01:53:24–01:53:46] |
| 36 | **contact** | 研究者曾推测双亲在场能提高幼崽存活率，但观察记录显示幼崽孵化后与父母几乎没有接触（**hardly any contact**）。老师提醒被动语态会改变语序，要跟住动词再听后续信息。 [01:53:47–01:55:04] |
| 37 | **protect** | 曾提出雄性留在附近可能是为了保护雌性免受其他雄性侵扰。 [01:55:06–01:55:17] |
| 38 | **tails** | 研究者把微型 GPS 固定在蜥蜴尾巴上；**fix … onto** 对应题目里的 attach。注意复数。 [01:55:18–01:56:26] |
| 39 | **steps** | GPS 追踪 12 天；数据不只包括位置，也包括期间走了多少步。**how many** 对应题目中的 number。 [01:56:27–01:57:28] |
| 40 | **injuries** | 一个假设是雄性蜥蜴会彼此造成严重伤害；后面的 **preventing this** 中 this 回指 injuries，题目表达“减少受伤机会”。答案复数。 [01:57:29–01:59:12] |

老师再次强调：遇到被动、定语/状语或其他结构导致语序变化时，按词性与句子关系灵活定位；答案可能先于或后于题目关键词出现；并列/转折以及代词回指都可能影响判断。[01:43:22–01:43:40; 01:59:14–01:59:48]

### 3. 环保类词汇

环保题材的专业词相对集中，但可能超出日常词汇范围。课堂讲解：[02:00:00–02:05:09]

- **environmental**（环境的）、**carbon dioxide**（二氧化碳；听到化学物质时写单词而非化学式）、**container**（容器）、**contaminant**（污染物；录音识别成 *contaminator*，拼写需核课件）、**deteriorate**（恶化）、**solar**（太阳能/太阳的）、**electricity**（电力）。[02:00:00–02:01:34]
- **extinction**（灭绝）、**incineration**（焚烧；如 **incineration plant** 焚烧厂）、**nuclear**（核能/核的）、**greenhouse**（温室）、**recycle**（回收利用）、**installation**（安装/设施；录音中老师给的中文解释听似“隔热材料”，待核）、**tunnel**（隧道）。[02:01:59–02:03:36]
- **habitat**（动物栖息地）、**organic**（有机的）、**conservation**（保护/保育）。老师提醒 habitat 用于动物栖息环境，不宜直接当作人类居住地的通用词。[02:04:00–02:05:09]

## 四、简答题：按疑问词定位，按回答作答

老师将简答题归纳为三点：[02:05:22–02:07:12]

1. 先看疑问词，判断需要听的人、地点、时间、事物等答案类型，并据此定位。
2. 按字数限制写单词或短语，不要因为题目是 **Why** 就写完整的 because 从句。
3. 对话中的简答题通常是一问一答，答案以回应者实际说出的内容为准；独白中则需回到关键词定位，问句提示作用较弱。

例题要求 **no more than two words**，课堂分析题目先判断答案类别，再核对答案：[02:07:43–02:12:16]

- 第 7 题：学生喜欢吃什么？答案 **seafood**（一个词）。[02:10:51–02:11:06]
- 第 8 题：学生玩什么运动？答案 **tennis**；注意双写 n。[02:11:08–02:11:16]
- 第 9 题：偏好的交通方式。提问者先提到 **trains**，但回答者说 **I like catching the train**；老师强调听对方回答而不是把问题中的词照抄。课堂口头答案听似 **train**，并提醒冠词与复数 s；最终答案具体冠词形式待核。[02:11:16–02:12:08]
- 第 10 题：学生在什么时候发现衣服/校服相关物品？答案 **this afternoon**。[02:12:09–02:12:16]

课堂补充规则：**对话中，简答题答案以说话人的回答为准，并且所听即所得；注意冠词 a/an/the 以及名词复数 s。**[02:12:17–02:13:46]
